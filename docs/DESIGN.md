# SYNC — Дизайн-система v1

> Вайб: **«тёплое утро вдвоём»** — светлый, воздушный, уютный.
> Не клиника, не детский сад, не стереотипно-розовый. Тёплый крем + глина-роза + шалфей.

## Цвета (light only для MVP)

| Токен | Значение | Где |
|---|---|---|
| `bg` | `#FFF8F4` (тёплый крем) | фон приложения |
| `surface` | `#FFFFFF` | карточки |
| `primary` | `#E8837F` (rose-clay) | акценты, кнопки |
| `primary-soft` | `#FDE8E4` | подложки иконок, ховеры |
| `accent` | `#F0A08C` (персик) | градиенты primary→accent |
| `text` | `#3B2E3A` (тёмная слива) | основной текст |
| `text-muted` | `#8A7B86` | вторичный текст |
| `success` | `#7FA98F` (шалфей) | «сделал ✅», стреак |
| `danger` | `#D96C6C` | удаление, «не то» |

Тени: карточки `0 8px 30px rgba(232,131,127,.14)`, hover `0 12px 40px rgba(232,131,127,.20)`.
Градиент фирменный: `linear-gradient(135deg, #E8837F, #F0A08C)` — только на главных кнопках и карточке дня.

## Типографика

- **Nunito** (Google Fonts, self-host через next/font): 400/600/700/800. Поддержка кириллицы.
- Заголовки: 800, 24–28px. Текст: 16–17px, 600. Кнопки: 700, 15–16px.
- Никаких «капитель-лайт-тонких» шрифтов — приложение для чтения с телефона.

## Формы и иконки

- Карточки: `rounded-[24px]`, padding 20–24px, surface на bg.
- Кнопки: pill `rounded-full`, высота 52px, primary-градиент или soft-подложка.
- Иконки: **lucide-react**, stroke 1.8, размер 20–24. Иконки в цветных кружках `bg-primary-soft text-primary`.
- **Без кастомных эмодзи и без системных эмодзи в UI** — только SVG-иконки. Эмодзи допустимы только в контенте подсказок (фразы), и то дозированно.
- Скругления везде одинаковые: карточки 24, внутренние элементы 16, кнопки-full.

## Анимации (framer-motion)

Правило: **плавно и незаметно**. Всё spring, длительность 0.3–0.5s.

| Элемент | Анимация |
|---|---|
| Смена экрана | fade + slideY 12px, spring `{ damping: 24, stiffness: 200 }` |
| Карточка дня | появление: scale 0.96→1 + fade, лёгкое свечение |
| Нажатие кнопки | `whileTap: { scale: 0.97 }` |
| Выбор карточек онбординга | выбранная — pop (scale 1.03) + рамка primary; невыбранные — fade к muted |
| Фидбек «сделал» | кнопка «взрывается» в success (spring), карточка мягко уходит вверх |
| Стреак | кольцо прогресса с анимацией stroke-dashoffset |
| Кнопки «не то» | лёгкий shake (x: [0,-4,4,-2,0]) — но без агрессии |

**Запрещено:** конфетти-дождь на каждый чих, bounce-перебор, карусели, параллакс.

## Микрокопия (голос продукта)

- Тёплая, короткая, с лёгкой иронией — но ирония всегда про ситуацию или про действия партнёра, **никогда про неё**.
- «Переводчик эмпатии», а не «трекер».
- Примеры: «Твоя задача — тишина. Борщ — по желанию», «Сегодня она не хочет разговоров. Хочет, чтобы ты просто был рядом. Это сложнее, чем кажется. Ты справишься.»
- Никаких «терпи», «успокойся», «это всё гормоны».

## Экраны-состояния

- Пустые состояния: иллюстрация-иконка в круге + 1 строка текста + действие. Без скелетонов-скелетонов.
- Загрузка карточки: мягкий пульс на месте текста (opacity 0.4→0.7), не спиннер.

## Что НЕ делаем в MVP

- Тёмная тема (позже, если попросят).
- Кастомные шрифты с экзотикой, градиентные «неоновые» кнопки.
- Анимации, которые замедляют первый рендер.
