# SYNC — «переводчик эмпатии» для пар
Полный обзор продукта и технической реализации (август 2026)

---

## 1. Суть продукта

SYNC — веб-приложение (PWA) для пар: девушка один раз описывает «профиль заботы» — что её поддерживает, что бесит, какие слова работают (послание). Парень каждый день получает **одну персонализированную подсказку**, как позаботиться именно сегодня. Не трекер, не медицинский сервис: это «переводчик эмпатии» — превращает её состояние в понятные ему действия.

Ключевая механика:
- **Она** отмечает настроение/состояние (пульс) и свой цикл — «на пальцах», без календарей.
- **Он** видит её состояние через **тамагочи-маскота** и получает карточку дня.
- За реальные поступки (отметка GOOD) он прокачивает маскота, копит перки и кэшбэк — но питомец никогда не наказывает за невнимание.
- Виральность: приглашение пары по коду — от неё к нему.

## 3. Архитектура и приватность (принцип)

**Ровно 4 сущности в БД:** User, CoupleProfile, DailyPrompt, Achievement.

**Железное правило приватности:** даты цикла НИКОГДА не покидают устройство. История, прогноз, дни — только localStorage (zustand persist, ключ `sync-device-v1`). На сервер уходит только:
- фаза цикла (число 1..40), настроение, отметка «не трогать»
- цвета дней (dayStates) — по согласию, числами без дат

Партнёр видит: день цикла, фазу, цвета дней, настроение — но не даты и не историю.

## 4. Роли и онбординг

### Входы
- Почта + пароль (регистрация за 10 секунд)
- Google OAuth
- Yandex OAuth
- После входа новичок без пары попадает на **/choose**: «Я создаю пару» или «У меня есть код»

### Онбординг OWNER (она)
1. **Послание** (бывш. «инструкция»): карточки-выборы — еда, пространство, слова, «что бесит», шуточная строка. Один раз — и подсказки становятся персональными.
2. Приглашение партнёра: код пары (6 символов), ссылка.

### Онбординг PARTNER (он)
1. Ввод кода (/join) → вступление в пару.
2. Микро-опрос из 3 вопросов (реакции, боли, стиль сигналов) — можно пропустить.
3. Видит её послание («бутылка»).

## 5. Функции (что и как работает)

### 5.1 Карточка дня (ядро)
- Одна подсказка в день на пару: ИИ-генерация (DeepSeek) по контексту: её послание, фаза цикла, настроение, цвета дней, его стиль (из микро-опроса), история его поступков.
- Лимит: 2 ИИ-генерации/день на пару → дальше кураторская библиотека (безлимит).
- Тон: ирония про ситуацию, не про неё; блоклист; кнопка «не то» → фидбек в датасет.
- Реакции: GOOD (забота засчитана), MISSED, BAD.
- Плейсхолдеры: «завари ей чай», «скажи, что заметил» — без «инструкции по эксплуатации человека».

### 5.2 Пульс (её состояние)
- 3 настроения: «Всё бесит» (TERRIBLE), «Так себе» (MEH), «Отлично» (GREAT).
- Отметка «Не трогать» (needsSpace) на сегодня.
- Погода партнёра = её настроение (приоритет), фаза цикла — фолбэк.

### 5.3 Цикл (только на устройстве)
- Ввод: «Месячные начались сегодня» / сетка-чипы дней.
- Карточка дня + луна-индикатор фаз (menstrual/follicular/ovulation/luteal).
- Прогноз следующего старта, отклонения от средней длины цикла — из истории на устройстве.
- У партнёра: полоска-прогресс 28 сегментов + день.

### 5.4 Тамагочи-маскот (у партнёра)
- Пиксельное облако с кошачьими ушками (canvas, 32×32 логических).
- **Отражает ЕЁ состояние**, не его долг: никакой вины за невнимание.
- Эмоции: happy (жёлто-зелёный, прыгает, подмигивает с искоркой), sad (синий, заворачивается в облако, слёзки), spiky (красный, трясётся, шипит паром, «жилка» на лбу), neutral.
- Маппинг: «не трогать» → spiky; красный день (боль) → sad «всё болит»; «бесит» → spiky; иначе по настроению.
- Тап — сердечки (без XP); GOOD-поступок — всплеск + XP.
- Тучки-эффекты по погоде: белые/дождевые/грозовые с молниями.

### 5.5 Геймификация
- XP и уровни-перки (например: «Идеальный плед», «Хранитель тишины»).
- Streak — дни подряд с поступками.
- **Кэшбэк заботы**: реальные GOOD-действия копят баланс.
- Ачивки (Achievement): ninja_7d, gentleman_10, first_cycle_together, cycle_reward.
- Карточка **«Его забота»** у Оли: счётчик поступков, streak, уровень, недавние действия — она видит его старания.
- Календарь-история: месяцы с отметками стартов и цветами дней (на устройстве).

### 5.6 Послание («бутылка»)
- /instruction — её послание для него: карточки-выборы, читается как письмо в бутылке.

### 5.7 SOS
- Быстрая генерация фразы/действия, когда нужно «сейчас» (лимит в день).

### 5.8 Уведомления (Web Push)
- VAPID-ключи, service worker v3 (push + notificationclick → /today).
- Расписание: «Утром» (9:00), «Когда она встала» (10:00), «Вечером» (20:00).
- Внутренний tick (cron каждые 30 мин на VPS) шлёт карточку дня, антидубль на день, мёртвые подписки чистятся.
- iOS: работает только из PWA-ярлыка (iOS 16.4+), требует HTTPS.

### 5.9 Настройки
- Тема (светлая/тёмная/система), «Мой стиль заботы», время карточки, уведомления (вкл/выкл), ачивки, календарь, выход, удаление аккаунта.

## 6. Визуал и анимации

### 6.1 Фон-океан (главная «фишка»)
- Пиксельный canvas 480×720 (S=2 — мельче пиксели), image-rendering: pixelated.
- **Погружение при прокрутке (dive)**: канвас фиксирован, но горизонт «поднимается» с ростом scrollY — экран заливает вода, сверху остаётся полоска неба. Без transform-сдвигов (не ломается на iOS).
- Плавные градиенты (небо и вода — интерполяция по палитрам через lerpColor, парсер hex и rgb()).
- **Над водой** (по погоде): солнце/луна, мерцающие звёзды, многослойные облака с «хвостами», дождь, ветвистые молнии, чайки-«галочки» с машущими крыльями, парусник, дальняя скала.
- **Под водой** (по погоде):
  - Отлично: стайки рыб, дельфин (выпрыгивает с брызгами), скат с машущими крыльями, медузы, планктон.
  - Так себе: акулы (ближняя — крупный силуэт).
  - Всё бесит: мигающие красные глаза в темноте (с ореолом, ближние — крупные), вода почти чёрная.
- Дно: песок с крапинками, камни, ракушки, растения с листьями, краб (бегает, шевелит клешнями), осьминог (щупальца перебирает), морская звезда.
- Передний план: крупные объекты поверх (рыба/акула/глаза), пузырьки, световые столбы.

### 6.2 UI-анимации
- framer-motion: появление карточек (fade + y), тап-масштаб (whileTap), shake при ошибке ввода кода, AnimatePresence между шагами онбординга.
- Карусель дней, полоска цикла, прогресс XP.

### 6.3 Стиль
- Пиксельный шрифт Press Start 2P (логотип, заголовки, XP), скругления (не пиксельные рамки), стекломорфизм удалён по решению владельца.
- Иконка: пиксельное сердце 12/16 сетки на тёмно-океанском фоне.

## 7. ИИ-пайплайн
- Контекст запроса: послание (выборы), фаза/день цикла, настроение, needsSpace, деньStates, его стиль заботы, недавние поступки.
- Промпт-правила: ирония про ситуацию, не про неё; блоклист тем; коротко; без «инструкций по эксплуатации человека».
- Фолбэк: кураторская библиотека, если лимит или сбой API.
- Фидбек «не то» → в датасет.

## 8. Инфраструктура и деплой

- **VPS (Москва, 155.212.169.168)**: /root/sync, PM2 (процесс sync), Node 22 в /opt/node22 (системный v18 не тронут — KatoCRM работает на нём).
- **nginx (katocrm_nginx, Docker)**: stream 443 по SNI — katocrm.ru → KatoCRM (8443), golubot.online → 8444 → SYNC (localhost:3000 хоста). default → 2053 (VPN-мост, не тронут).
- HTTPS: Let's Encrypt (certbot-контейнер, webroot), автопродление каждые 12ч (контейнер katocrm_certbot — проверять!).
- UFW: 22/80/443/3000/8443.
- Cron VPS: push-tick каждые 30 мин.
- Локальная разработка: Windows (git-bash), npm start (production-сборка), браузер-тесты.
- Медленные туннели (lhr.life/cloudflared) — только как временные, заменены доменом.

## 10. Ключевые решения (история)
- Видео-маскоты отменены (chroma-key съедал цвета, iOS не играет webm-альфу) → только пиксель.
- Свайп-кольцо ввода цикла отменено → кнопки/чипы (UX: минимум текста, 1 действие = 1 кнопка).
- «Инструкция» → «Послание» (язык заботы, не эксплуатации).
- Маскот = эмоция ЕЁ состояния; прокачка только за реальные поступки.
- Даты цикла никогда не на сервере.
