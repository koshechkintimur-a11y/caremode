## 1. НАВИГАЦИЯ (структура роутов)

```
/ (welcome)  →  хуки → «Как это работает» → /register
/privacy     — политика (публичная, из футеров)

/auth:
  /login            — вход (почта / Google / Яндекс)
  /register         — роль (создать пару / есть код) + форма + согласие

/app (шапка общая): [← назад] [sync. лого → /today] [бутылка → /instruction] [⚙ → /settings]
  /choose           — новичок без пары: «Я создаю пару» / «У меня есть код»
  /onboarding       — Оля: послание (4 шага: Ты → Бесит → Цикл → Штрихи)
  /onboarding/partner — его микро-опрос (3 вопроса) — открывается из /join после вступления
  /join             — ввод кода пары (партнёр)
  /invite           — её код для отправки
  /today            — ГЛАВНЫЙ экран (роль определяет содержимое)
  /instruction      — послание: бутылка (он) / свиток (оба) / приглашение (она)
  /settings         — настройки (вкл. Календарь цикла →)
  /calendar         — история цикла (только устройство)
  /paywall          — заглушка подписки (не в шапке, при исчерпании лимита)
```

Переходы:
- Оля: /onboarding → /instruction → /invite → (ждёт) → /today
- Партнёр: /join (код) → /onboarding/partner → /today
- Без пары после входа (OAuth): /choose
- /today без пары: OWNER → /onboarding, PARTNER → /join (через guard) — теперь оба через /choose

## 4. ПРОЧИЕ ЭКРАНЫ

**/instruction** — закрытая бутылка (он): «Послание {имя}» + [Открыть] → свиток: ТАЙНАЯ ШПАРГАЛКА / Делать / Не делать / Фраза-пароль / Её суперсила. Она: заголовок «Твоё послание для {него}» + [Отправить партнёру] [Поделиться] [Переписать].

**/settings** — секции сверху вниз: Оформление (светлая/тёмная/система) → Приватность (Режим инкогнито) → Моё послание → Календарь цикла → Подсказки → Мой стиль заботы → Данные цикла (первый день, список уютного) → Когда присылать карточку (9:00/10:00/20:00 + уведомления) → Ачивки → Удаление данных → Выйти → ссылка на политику.

**/calendar** — заголовок + «Твоя история» (сетка месяцев, старты, цвета) + легенда + подпись «хранится только на устройстве».

**/choose** — 2 карточки (создать пару / есть код). **/join** — поле кода + кнопка. **/invite** — код крупно + «Скопировать».

## 5. РАЗБОР КОФАУНДЕРА: что расположено правильно, что стоит менять

### ✅ Хорошо
1. **Карточка дня в верхней трети** у партнёра — действие видно без скролла.
2. **Маскот — первый** — эмоциональный якорь, «её состояние» читается мгновенно.
3. **SOS отдельным цветом** (красный) — не спутаешь с остальным.
4. **Пульс Оли выше всего** — её главное действие (отметка состояния) в один тап.
5. **Код/вступление** — 2 тапа, без лишнего.
6. **Бутылка в шапке** — якорь «послание» всегда доступен.

### ⚠️ Что бы я изменил (по приоритету)

**1. SOS спрятан в самый низ (риск!)**
Партнёр в кризисе скроллит в поисках кнопки. SOS должен быть **всегда виден**: плавающая кнопка (fixed, над нижним краем) или иконка в шапке. Сейчас: 8 блоков выше него.

**2. Дублирование XP у партнёра (3 места!)**
«+1 GOOD…» в подписи маскота + «Статус: … N GOOD» + строка «ИИ-подсказки 1/2». Это три строки про одно и то же. Слить в один компактный блок XP под карточкой («Хранитель тишины · 16 GOOD · ещё 9 до "Читает её"»), подпись маскота оставить только про эмоцию.

**3. У Оли «Режим прозрачности» занимает первое место**
Служебный текст ради одной пары (Дима/Оля). Переместить в самый низ (или в настройки). Первое место — пульс («Как ты сейчас?»).

**4. Кэшбэк выше «Моих дней»**
Кэшбэк появляется раз в цикл, «Мои дни» — ежедневная механика. Частые действия должны быть выше редких: поменять местами блоки 5 и 6.

**5. Карточка дня vs маскот (спорное)**
Сейчас маскот выше карточки — внимание сначала уходит «погладить», потом к делу. Вариант А: карточка первой (маскот ниже) — действие важнее. Вариант Б (я за него): оставить маскота, но уменьшить его (ширина 425 → ~340) — он станет компактнее, карточка поднимется. Не ломает эмоциональный якорь.

**6. Обучалка перекрывает маскота**
CoachTips позиционируется поверх (top-28%) — на маленьких экранах может накрывать мордочку. Сместить вниз (bottom-24) — подсказка про маскота, но не поверх него.

**7. Мелочи**
- «Серия заботы» + «ИИ-подсказки» + статус — три строки подряд одного размера; сделать один блок прогресса.
- У Оли «Подсказка для него» и её пульс — рядом, хорошо; но «Твоя фаза / Настроение» (сетка) дублирует пульс выше — можно убрать или объединить.
- /paywall не в шапке — правильно (не спамить).

### Итоговая рекомендация (что сделать в первую очередь)
1. SOS → плавающая кнопка (fixed, видна всегда) — **безопасность фичи**.
2. Объединить 3 строки XP в один блок под карточкой.
3. Оля: плашка «прозрачности» вниз, кэшбэк ниже «Моих дней».
4. Маскот компактнее (340px) — карточка поднимается.
5. CoachTips — вниз, не поверх маскота.
